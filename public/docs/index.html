Ultimate POS API Documentation

Complete REST API reference for Ultimate POS. All API endpoints are prefixed with /api/v1.

Base URL: /api/v1

Overview

The Ultimate POS API provides programmatic access to all core POS functions including products, sales, purchases, inventory, contacts, expenses, reports, and accounts management.

FeatureDescription
ProtocolHTTP/HTTPS
FormatJSON
AuthenticationOAuth2 (Bearer Token via Passport)
Base Path/api/v1
Host
Total Endpoints155

Authentication

This API uses Laravel Passport for OAuth2 authentication. All protected endpoints require a Bearer token in the Authorization header.

Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGciOi...

To obtain a token, call the login endpoint with valid credentials. Tokens expire after 15 days. Use the refresh endpoint to get a new token.

API Credentials

ParameterValueENV Variable
UsernameadminAPI_USERNAME
PasswordAdiyoga1996API_PASSWORD
Credentials are configurable via .env file: 
API_USERNAME=admin
API_PASSWORD=Adiyoga1996
Change these values and restart the application to use different credentials.

Response Format

All API responses follow a standard JSON format:

Success Response

{
  "success": true,
  "data": { ... },
  "meta": {
    "current_page": 1,
    "last_page": 5,
    "per_page": 20,
    "total": 100
  }
}

Error Response

{
  "success": false,
  "message": "Error description"
}

Auth Endpoints

POST /api/v1/login Public

Authenticate and receive an OAuth2 access token.

ParameterTypeRequiredDescription
usernamestringYesAPI username (default: admin)
passwordstringYesAPI password (default: Adiyoga1996)
Example Request
curl -X POST /api/v1/login \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{"username":"admin","password":"Adiyoga1996"}'
Example Response (200)
{
  "success": true,
  "token_type": "Bearer",
  "expires_in": 1296000,
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciO...",
  "refresh_token": "def50200cbf895f9...",
  "user": {
    "id": 1,
    "username": "admin",
    "email": "admin@example.com",
    "full_name": "Admin User",
    "business_id": 1
  }
}
Error Response (401)
{
  "success": false,
  "message": "Invalid credentials."
}
POST /api/v1/refresh Public

Refresh an expired access token.

ParameterTypeRequiredDescription
refresh_tokenstringYesThe refresh token from login response
curl -X POST /api/v1/refresh \
  -H "Content-Type: application/json" \
  -d '{"refresh_token":"def50200cbf895f9..."}'
POST /api/v1/logout Bearer Token

Revoke the current access token.

curl -X POST /api/v1/logout \
  -H "Authorization: Bearer {token}"
GET /api/v1/user Bearer Token

Get authenticated user profile.

curl -X GET /api/v1/user \
  -H "Authorization: Bearer {token}"
{
  "success": true,
  "data": {
    "id": 1,
    "username": "admin",
    "email": "admin@example.com",
    "full_name": "Admin User",
    "business_id": 1
  }
}

Products

GET /api/v1/products Bearer Token

List all products with pagination.

Query ParameterTypeDescription
per_pageintegerItems per page (default: 20)
category_idintegerFilter by category
brand_idintegerFilter by brand
searchstringSearch by name or SKU
curl -X GET "/api/v1/products?per_page=10&search=coffee" \
  -H "Authorization: Bearer {token}"
POST /api/v1/products Bearer Token

Create a new product.

ParameterTypeRequiredDescription
namestringYesProduct name
skustringYesProduct SKU code
unit_idintegerYesUnit of measurement ID
typestringYessingle or variable
category_idintegerNoCategory ID
brand_idintegerNoBrand ID
taxintegerNoTax rate ID
alert_quantitynumericNoLow stock alert
curl -X POST /api/v1/products \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "New Product",
    "sku": "SKU001",
    "unit_id": 1,
    "type": "single",
    "category_id": 1,
    "brand_id": 1,
    "alert_quantity": 10
  }'
GET /api/v1/products/{id} Bearer Token

Get product details including brand, unit, category, variations, and stock.

curl -X GET /api/v1/products/1 \
  -H "Authorization: Bearer {token}"
PUT /api/v1/products/{id} Bearer Token

Update an existing product.

curl -X PUT /api/v1/products/1 \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{"name":"Updated Name","sku":"SKU002"}'
DELETE /api/v1/products/{id} Bearer Token

Delete a product (only if no transactions exist).

curl -X DELETE /api/v1/products/1 \
  -H "Authorization: Bearer {token}"

List all sales transactions with pagination.

Query ParameterTypeDescription
per_pageintegerItems per page (default: 20)

contact_idintegerFilter by customer
from_datedateStart date (Y-m-d)

POST /api/v1/sells Bearer Token

Create a new sale transaction.

ParameterTypeRequiredDescription
contact_idintegerYesCustomer ID
transaction_datedateYesTransaction date
location_idintegerYesBusiness location ID
productsarrayYesArray of product objects
products.*.variation_idintegerYesVariation ID
products.*.quantitynumericYesQuantity
products.*.unit_pricenumericYesUnit selling price
statusstringNodraft or final (default: final)
discount_amountnumericNoTotal discount
shipping_chargesnumericNoShipping charges
paymentobjectNoPayment details { "amount", "method" }
curl -X POST /api/v1/sells \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "contact_id": 1,
    "transaction_date": "2026-06-17",
    "location_id": 1,
    "products": [
      {
        "variation_id": 1,
        "quantity": 2,
        "unit_price": 50000
      }
    ],
    "status": "final",
    "payment": {
      "amount": 100000,
      "method": "cash"
    }
  }'
